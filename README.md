# Windows PC セットアップ手順書

新しくWindows PCをセットアップする際の手順を記録します。

## 1. 初期設定 (OS Setup)

### Microsoftアカウントのユーザーフォルダー名を任意のものにする
Microsoftアカウントで初期設定を行うと、ユーザーフォルダー名がアカウントの最初の5文字などに自動設定されてしまいます。これを任意の名前にするための手順です。

1. **Microsoftアカウントをローカルアカウントに切り替える**
   - 「設定」→「アカウント」→「ユーザーの情報」から「ローカルアカウントでのサインインに切り替える」を選択。
2. **新しいローカルアカウントを作成し管理者に設定**
   - 変更したい希望のユーザー名で新しいローカルアカウントを作成し、アカウントの種類を「管理者」に変更する。
3. **作成したローカルアカウントでログインし、Microsoftアカウントに切り替える**
   - 新しいアカウントでサインインし、再度Microsoftアカウントに関連付け直す。
4. **元のローカルアカウントを削除**
   - 不要になった元の（初期設定時の）アカウントを削除する。

### BitLocker 回復キーのバックアップ
もしものトラブル時にドライブを復号できるよう、回復キーを安全な場所に控えます。
1. 「設定」→「システム」→「ストレージ」→「ストレージの詳細設定」→「ディスクとボリューム」を開く。
2. 起動ドライブ（通常はC:）を選択し「プロパティ」をクリック。
3. 「BitLocker の設定」をクリック。
4. 「回復キーのバックアップ」を選択。
5. 「ファイルに保存する」や「印刷する」などで、Microsoftアカウント以外（USBメモリや紙のメモなど）の安全な場所にも保存しておく。

## 2. システム設定 (System Settings)

### 右クリックメニューを旧仕様に戻す
Windows 11の右クリックメニュー（コンテキストメニュー）を、以前の使い慣れたスタイルに戻します。
1. Windows ターミナル（管理者）を開く
2. 以下のコマンドを実行
   ```powershell
   reg.exe add "HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32" /f /ve
   ```
3. パソコンを再起動（またはエクスプローラーを再起動）して反映
### タスクバーのカスタマイズ
- **左寄せに変更**
  - 「設定」→「個人用設定」→「タスクバー」→「タスクバーの動作」→「タスクバーの配置」を「左揃え」に変更。
- **不要な項目の非表示**
  - 「タスクバー項目」から「検索」「タスク ビュー」「ウィジェット」「チャット」など、不要なものをオフにする。

### 仮想メモリの設定
初期値と最大サイズを同じにして、ファイル断片化を抑制します。
1. 「設定」→「システム」→「詳細情報」→「システムの詳細設定」を開く。
2. 「詳細設定」タブのパフォーマンス「設定」をクリック。
3. 「詳細設定」タブの仮想メモリ「変更」をクリック。
4. 「すべてのドライブのパージング ファイルのサイズを自動的に管理する」のチェックを外す。
5. 「カスタムサイズ」を選択し、「初期サイズ」と「最大サイズ」に同じ値を入力して「設定」をクリック。

### フォルダーオプションの変更
ファイル操作を効率化し、開発に必要な情報を表示させます。
- **ファイル名拡張子を表示**
  - エクスプローラーの「表示」→「表示」→「ファイル名拡張子」にチェックを入れる。
- **隠しファイルを表示**
  - エクスプローラーの「表示」→「表示」→「隠しファイル」にチェックを入れる。

### JIS配列/US配列キーボードの共存設定
内蔵キーボード（JIS）と外付けキーボード（US）などを使い分ける際、個別にレイアウトを認識させる設定です。

#### 1. システムキーボードレイアウトの変更
1. 「設定」→「時刻と言語」→「言語と地域」を開く。
2. 「日本語」の「...」から「言語のオプション」をクリック。
3. キーボード欄の「レイアウトを変更する」をクリック。
4. 「接続済みキーボードレイアウトを使用する」を選択し、再起動する。

#### 2. 内蔵キーボードのレイアウト固定（レジストリ操作）
上記設定だけでは内蔵キーボードがUS認識されてしまう場合、特定のデバイスに対してJIS配列を強制します。

1. **デバイスマネージャーを開いてデバイスインスタンスパスをコピーする**
   - `Win + X` -> `M` を押下して「デバイスマネージャー」を開く。
   - 「キーボード」→「標準 PS/2 キーボード」（または対象のデバイス）を右クリックして「プロパティ」を選択。
   - 「詳細」タブを開き、プロパティのドロップダウンから「デバイス インスタンス パス」を選択。
   - 表示された「値」を右クリックしてコピーする。
   - ※この値は後のレジストリ登録で使用します。
2. **レジストリの登録**
   - 以下の内容を `.reg` ファイル（UTF-16 LE）として作成（ `@@@` はコピーしたパスに置換）。
     ```reg
     Windows Registry Editor Version 5.00

     [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\@@@\Device Parameters]
     "OverrideKeyboardType"=dword:00000007
     "OverrideKeyboardSubtype"=dword:00000002
     ```
   - ファイルを実行して登録し、再起動して反映を確認。

### IMEの設定（Ctrl + Spaceで日本語入力切替）
US配列キーボードを使用する場合や、Linux/Macと操作感を合わせるために、Ctrl + Spaceで日本語入力を切り替える設定です。

1. タスクバーのIMEアイコン（「あ」または「A」）を右クリックし、「設定」を選択。
2. 「キーとタッチのカスタマイズ」をクリック。
3. 「キーの割り当て」セクションで、「各キーに好みの機能を割り当てる」を **オン** にする。
4. **Ctrl + Space** のプルダウンメニューから **「IME-オン/オフ」** を選択。

### WSL / ターミナル設定

#### 1. .wslconfig の作成
WSL2のメモリ使用量やディスクサイズを事前に制限・設定します。
1. `C:\Users\<ユーザー名>\.wslconfig` ファイルを作成（または編集）。
2. 以下の内容を記述（スペックに合わせて調整）
   ```ini
   [wsl2]
   memory=4GB # PCメモリの半分〜1/4程度
   processors=2 # 使用するCPUコア数
   swap=8GB
   localhostForwarding=true
   defaultVhdSize=256GB # ディスクの最大サイズを指定
   ```

#### 2. WSL2 / Ubuntu のインストール
1. Windows ターミナル（管理者）で以下を実行
   ```powershell
   wsl --install
   ```
2. 再起動後、Ubuntuのユーザー名とパスワードを設定。
3. 必要に応じて最新の状態に更新
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```
4. WSLをシャットダウンして設定を反映（1の手順を後から行った場合など）
   ```powershell
   wsl --shutdown
   ```

#### PowerShell 7 のインストール
最新の PowerShell を winget を使用してインストールします。
1. Windows ターミナルを開く。
2. 以下のコマンドを実行
   ```powershell
   winget install --id Microsoft.PowerShell --source winget
   ```
